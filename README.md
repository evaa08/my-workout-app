# Pulse Workout Coach — Updated
This version includes 50+ searchable common exercises, synonym-friendly muscle-group search, links to YouTube video search results, and sets/reps tracking saved in localStorage.

## GitHub Pages
Upload the **six files inside this folder** into the root of your existing GitHub repository, replacing the older versions. GitHub Pages will republish automatically. Refresh the website after deployment.

## Video quality
Links open YouTube searches, not vetted individual videos. Select a reputable demonstration. Video availability and quality vary. This is not an embedded video library.

## Existing routines
Uses the original `pulse-workout-v1` localStorage key so routines from the earlier simple version remain available in the same browser. Back up important routine information before replacing code.
